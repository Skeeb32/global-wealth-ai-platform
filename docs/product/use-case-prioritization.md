# Use-case prioritization

Score candidates 1–5 for volume, manual effort, error exposure, data readiness, and implementation ease. Higher is more favorable. Proposed weighted score: `0.20 × volume + 0.25 × effort + 0.20 × error exposure + 0.20 × readiness + 0.15 × ease`. Sponsors must agree on weights before selection.

Hard prerequisites: named business owner, authoritative rule and reference result, approved data access, defined review controls, measurable baseline, and feasible support ownership. A high score does not bypass these gates.

Start with one deterministic metric and its reconciliation workflow. Select the actual metric through discovery; do not invent fund-specific priorities.

Annual hours saved = annual cases × (minutes before − minutes after) / 60. Include required human review in the after measurement. Multiply by an agreed fully loaded hourly cost for labor value; report risk reduction separately unless Finance approves a valuation method.
